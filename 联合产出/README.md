# 联合产出：线代作业求解与可验证报告

## 这是什么

输入 6 道线代题（det / rref / eigen），输出：

- `results_linalg.json`：每题的解、自校验结果、校验依据
- `解题报告.md`：由 JSON 生成的报告（数字不手抄）

## 怎么跑

```bash
cd 联合产出
python3 solve_linalg.py      # 6/6 自校验通过
python3 make_report.py       # 生成 解题报告.md
```

零第三方依赖，Python 3.9+，分数用 `Fraction` 精确计算。

**为什么这仍然是"联合产出"而不是单人项目**：
当前的 6 道题是示例题，符号与步骤按通用惯例写；**没有搭档L 的规范审定，它只能证明"代码能算"，不能证明"作业能交"**。
这正是"单独做不到"的部分——不是缺代码，是缺"什么算对"的定义。

## 已知局限

1. eigen 只支持有理根（整数根 + 降次）；无理根/复根未实现。
2. 没有 PDF 排版（当前是 Markdown 报告）；C4C 的 LaTeX 管线未接进来。
3. 题目是示例题，不是搭档L 的真实课程题。
4. 自校验覆盖数值与结构，不覆盖排版（C4C 的 `λ²7λ10` 就是排版错误）。
